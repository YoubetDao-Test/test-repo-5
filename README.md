# Flow Bounty Platform

A decentralized bounty platform built on the Flow blockchain that allows users to create tasks, set rewards, submit work, and claim rewards.

## Project Overview

This platform connects task creators with contributors in a decentralized manner, using Flow blockchain for transparent and secure transactions.

### Core Features

- **User Authentication**: Connect with Flow wallet
- **Bounty Creation**: Create tasks with descriptions, rewards, and deadlines
- **Work Submission**: Submit completed work for review
- **Fund Management**: Secure escrow and reward distribution
- **Dispute Resolution**: Fair conflict resolution mechanism

## Technology Stack

- **Smart Contracts**: Cadence (Flow's smart contract language)
- **Backend**: Node.js/Express
- **Frontend**: React/Next.js
- **Blockchain Interaction**: Flow Client Library (FCL)
